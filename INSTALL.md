### **Quick Install · by [@B_KHANEMAN](https://github.com/b-khaneman)**

</div>

## One command (install + run)

```bash
curl -fsSL https://raw.githubusercontent.com/b-khaneman/jojo-backuper/main/bootstrap.sh | sudo bash
```

Then later:

```bash
sudo jojo
```

### Update from server

- Menu **`16) Update from GitHub`**
- Or: `sudo jojo update`
